# UPHIGH ONLINE

A clean, modern Amazon Associates website.

## How to Upload to GitHub Pages

1. Create a new repo named `uphigh-online`.
2. Upload:
   - index.html
   - style.css
3. Go to **Settings → Pages**.
4. Under “Source”, select:
   - Branch: `main`
   - Folder: `/root`
5. Save.

Your site will publish at:

`https://YOURUSERNAME.github.io/uphihg-online/`
